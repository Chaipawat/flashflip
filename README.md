# FlashFlip

เว็บฝึกจำคำศัพท์ภาษาอังกฤษสำหรับคนไทย ออกแบบจากฟีดแบ็กจริงของผู้ใช้สองข้อ:

1. **"ปัญหาที่น่าเบื่อที่สุดคือตอนต้องกรอกคำ"** → พิมพ์คำอังกฤษ 2–3 ตัวอักษรก็มีคำแนะนำให้เลือก แล้วแตะเลือกความหมายภาษาไทยจากพจนานุกรม ไม่ต้องพิมพ์ความหมายเอง
2. **"เอาคำที่ลืมมาไว้ในกอง แล้วสุ่มเล่นทุกวัน"** → หน้าแรกคือ "กองคำที่ยังจำไม่ได้" กดทีเดียวสุ่มฝึก คำที่จำได้ออกจากกอง คำที่จำไม่ได้อยู่ต่อ

## ฟีเจอร์

- เพิ่มคำแบบพิมพ์แล้วเลือก (autocomplete + keyboard ล้วน: พิมพ์ → Enter เลือก → Enter เพิ่ม) หรือพิมพ์ความหมายเองได้
- วางทีละหลายคำ (สูงสุด 500 บรรทัด) พิมพ์แค่คำอังกฤษก็เติมความหมายให้ รองรับ `คำ - ความหมาย` และ Copy จาก Excel / Google Sheets
- จัดคำเป็นกอง: สร้าง เปลี่ยนชื่อ ลบ แก้/ลบคำ (แตะคำเพื่อแก้ไข)
- สุ่มฝึก Flashcard ครั้งละไม่เกิน 20 ใบ จากทุกกองหรือเฉพาะกอง คีย์ลัด Space / ← / →
- ระบบทวน Leitner 6 ระดับ นัดวันกลับมาทวนที่ 00:00 เวลาไทย
- ชุดคำตัวอย่าง 16 กอง รวม 471 คำ เช่น เทคโนโลยี การศึกษา การเงิน อาหาร และสิ่งแวดล้อม (ปุ่ม "ลองใช้ด้วยคำตัวอย่าง" ในหน้าแรกตอนยังไม่มีคำ)
- Mobile-first, dark mode ตามระบบ, รองรับ reduced motion และ screen reader

## สถาปัตยกรรม

Next.js 16 App Router · React 19 · TypeScript strict · Tailwind CSS 4 · sonner · lucide-react · Vitest

```
src/
  app/                 หน้า / , /add , /deck/[id] , /study (+ loading / error ของแต่ละหน้า)
  components/
    app-provider.tsx   data layer: เก็บกอง คำ และสถานะทวนใน localStorage
    confirm-dialog.tsx, skeletons.tsx, error-state.tsx, sun-mascot.tsx, app-header.tsx
  lib/                 business logic แบบ pure function (ไม่ import React/Next) + unit test
    dictionary.ts      ค้นคำ: ขึ้นต้นด้วยคำที่พิมพ์มาก่อน แล้วตามด้วยคำที่มีอยู่ข้างใน
    parse-bulk.ts      แยกข้อความหลายบรรทัด (Tab, " - ", คำเดี่ยว) + ตรวจซ้ำ/ผิดรูปแบบ
    leitner.ts         คำนวณระดับและวันนัดทวน (ไม่ใช้ date library)
    study-session.ts   reducer ของรอบฝึก + กฎว่าคำไหนออกจากกอง
  data/
    dictionary.json    พจนานุกรม 1,387 คำ
    mock-decks.json    ชุดคำตัวอย่าง 16 กอง 471 คำ (สร้างจาก npm run mock)
scripts/generate-mock.mjs
docs/                  SPEC.md และ demo.html (ต้นแบบหน้าตา)
```

**ทำไมเก็บข้อมูลในเบราว์เซอร์ (ยังไม่มี Login):** รุ่นนี้ให้เพื่อนใช้คนเดียวก่อน จึงยังไม่ต่อ Supabase/Auth ตามที่ SPEC วางไว้ ข้อดีคือ deploy แล้วใช้ได้ทันทีและไม่ต้องเปิดฐานข้อมูลสาธารณะ
**ข้อจำกัด:** ข้อมูลอยู่แค่ในเบราว์เซอร์เครื่องนั้น ไม่ซิงก์ข้ามอุปกรณ์ และจะหายถ้าล้างข้อมูลเว็บไซต์ (เปิดหลายแท็บพร้อมกันได้ ระบบซิงก์ให้)

**ทำไมพจนานุกรมอยู่ฝั่ง client:** ค้นได้ทันทีทุกครั้งที่พิมพ์โดยไม่ต้องเรียก server โหลดแบบ dynamic import เฉพาะหน้าที่ใช้ และเปลี่ยนแหล่งข้อมูลได้โดยแก้ไฟล์เดียว

**ทำไม Leitner:** เข้าใจง่ายและทำนายได้ จำได้ → เว้นห่าง 1, 2, 4, 7, 14 วัน, จำไม่ได้ → กลับเข้ากองทันที คำที่เคยลืมในรอบเดียวกันจะยังอยู่ในกองแม้ตอบถูกทีหลัง

> ⚠️ **ข้อมูลพจนานุกรมสร้างโดย AI** และควรได้รับการตรวจทานก่อนใช้ในบริบทสำคัญ แก้ได้ที่ `src/data/dictionary.json` (รูปแบบอยู่ใน `docs/SPEC.md` หัวข้อ 5.1 และมี test ตรวจรูปแบบ)

## วิธีรัน

ต้องใช้ Node.js 20.9 ขึ้นไป

```bash
npm install
npm run dev        # http://localhost:3000
```

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run lint` | ตรวจโค้ด |
| `npm test` | unit test ของ `src/lib` |
| `npm run build` | build production |
| `npm run mock` | สร้าง `src/data/mock-decks.json` ใหม่ (`-- --seed 7 --random 40` เปลี่ยนชุดสุ่ม) |

## Deploy บน Vercel

1. Push repository ขึ้น GitHub
2. ที่ [vercel.com](https://vercel.com) → **Add New… → Project** → Import repository นี้
3. ใช้ค่าที่ตรวจพบอัตโนมัติ (Framework: Next.js, Build: `npm run build`) **ไม่ต้องตั้ง environment variable**
4. กด **Deploy** แล้วส่งลิงก์ให้เพื่อน
5. ทุกครั้งที่ push ขึ้น `main` Vercel จะ deploy ให้อัตโนมัติ

แนะนำให้เพื่อนเปิดลิงก์บนมือถือแล้วกด "เพิ่มไปยังหน้าจอหลัก" (Add to Home Screen) และใช้เบราว์เซอร์เดิมตลอด เพราะข้อมูลอยู่ในเบราว์เซอร์นั้น

## สิ่งที่จะทำต่อ

- ปุ่ม export/import สำรองข้อมูล (สำคัญที่สุดตราบใดที่ยังเก็บใน localStorage)
- ต่อ Supabase + Email Magic Link ตาม SPEC เมื่อต้องการซิงก์ข้ามเครื่องหรือหลายผู้ใช้ (`mock-decks.json` ใช้เป็น seed ได้)
- ตรวจทานพจนานุกรมกับแหล่งข้อมูลที่มีสิทธิ์ใช้งานชัดเจน
- E2E test สำหรับ flow เพิ่มคำ วางหลายคำ และฝึกครบหนึ่งรอบ
- อัปเกรด Vitest เป็น v4 เพื่อปิดช่องโหว่ใน dev dependency (ไม่กระทบ production)
